🛒 Zutaten

    👨‍🍳 Zubereitung

      ℹ️ API-Key erstellen

      So bekommst du deinen kostenlosen Schlüssel:

      1. Gehe auf das Google AI Studio.
      2. Melde dich mit deinem Google-Konto an.
      3. Klicke oben links auf "Get API key".
      4. Klicke auf den blauen Button "Create API key".
      5. Wähle (falls gefragt) ein Projekt aus oder erstelle ein neues.
      6. Kopiere den angezeigten Schlüssel (beginnt meist mit AIzaSy...).
      7. Füge den Schlüssel hier in der App ein und klicke auf Speichern.

      ☁️ Cloud Sync einrichten

      So verbindest du deine Geräte:

      Wir nutzen den kostenlosen Dienst JSONBin.io als deine private Cloud-Datenbank.

      1. Gehe auf jsonbin.io und erstelle ein kostenloses Konto.
      2. Klicke im Dashboard auf "Create Bin".
      3. Lösche den vorgegebenen Text, trage einfach {"init": true} ein und klicke auf "Save".
      4. Kopiere die Bin ID (steht oben in der URL oder im Dashboard) und füge sie in der App ein.
      5. Gehe links im Menü auf "API Keys" und kopiere den X-Master-Key (beginnt meist mit $2a$10$...). Füge ihn ebenfalls in der App ein.
      6. Klicke auf "In Cloud sichern". Öffne danach die App auf deinem zweiten Gerät, trage die gleichen Keys ein und drücke auf "Von Cloud laden"!
